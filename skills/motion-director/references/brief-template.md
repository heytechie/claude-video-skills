# Brief

Fill every field. Unknowns: ask once, in one message. If told "just go", infer from the repo / website and mark each inferred field `(assumed)`.

```
Product:            name, one-line what it does
Audience:           who watches, where (X feed, Product Hunt, landing page hero, YouTube pre-roll, sales deck)
Goal:               what the viewer should do after (sign up, join waitlist, upgrade, understand feature X)
The one message:    one sentence the viewer must remember
Must-show (≤5):     concrete product moments / features / numbers, in priority order
Proof:              real numbers, customer names, benchmarks (only real ones; never invent)
Tone:               e.g. calm-premium / energetic / playful / deadpan / cinematic
Brand:              colors (hex), display font, text font, logo file (SVG), wordmark rules
UI source:          Figma file / SVG exports / live app URL / component code path
References:         links or files + what to take from each (pacing? type? transitions?)
Length & formats:   e.g. 30 s 16:9 master + 9:16 and 1:1 cutdowns
Audio:              music only / music + SFX / VO (who, language) / silent (autoplay feeds)
Captions:           yes / no (burned-in for social if VO)
Deadline:           first look, final
Constraints:        legal lines, words to avoid, competitor mentions, accessibility
```

## Quality questions before you plan
1. What is the single most impressive thing the product does on screen?
2. What does the viewer's life look like *before* the product (the problem beat)?
3. What is countable (time saved, tasks done, $) to make proof concrete?
4. Where will this play, sound on or off? (Feeds autoplay muted: the story must work without audio; captions/kinetic type carry it.)
5. What is the first frame? It's the thumbnail and the hook.
