# Platforms

| Platform | Length | Aspect | Sound | Script notes |
|---|---|---|---|---|
| X (organic feature post) | 10–20 s (launch films can run 45–90 s organically) | 16:9 or 1:1 | autoplays muted | Motion in frame 0; story fully readable as text; the post text carries the CTA link |
| LinkedIn | 15–30 s | 1:1 or 4:5 (16:9 OK) | ~79 % watched muted | One audio source (music *or* VO) does better; brand in first 5 s; business outcome framing (time, money, team) |
| Reels / TikTok / Shorts | 15–30 s (ads 9–15 s) | 9:16 | sound-on culture, but captions required | Keep text inside the central safe band (~720×1200 of 1080×1920; avoid top ~15 % and bottom ~25 % UI); state the pitch by 3 s; faster cuts |
| YouTube pre-roll | 15–30 s | 16:9 | sound on | Skip button at 5 s: brand + hook before it |
| Landing page hero | 15–40 s, seamless loop | 16:9 | silent autoplay | No VO; end frame should loop back to the first; no "watch till the end" structures |
| Product Hunt / launch day | 30–60 s | 16:9 | mixed | Full story (P1/P2); provide a 15 s cutdown for social |
| In-app / changelog | 8–20 s | matches UI slot | silent | F1 micro glimpse; ends on where to find the feature |
| Sales deck / email | 20–45 s | 16:9 | often silent | Outcome + proof heavy; CTA = "book a demo" |

Multi-platform jobs: write one master script, then add a **Cutdowns** section listing which beats survive in each format (e.g. 15 s = hook + strongest proof + CTA; 9:16 = same beats, text re-flowed to the safe band).
