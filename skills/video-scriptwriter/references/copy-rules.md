# Copy rules

## Budgets
| Thing | Rule | Basis |
|---|---|---|
| Words per on-screen card | ≤ 6 (sweet spot 2–4) | top brand median 3–4; motion-director limit |
| Hold per card | ≥ 0.3 s × words + 0.5 s (≈ ≤ 3 words/s) | silent reading ~4 wps avg; text-only cards need margin |
| Short label | ≥ 0.8 s settled | |
| Key headline / number / UI state | ≥ 1.5 s settled | |
| End line / CTA | ≥ 2 s | |
| Lines on screen | 1 at a time (2 max), ≤ 42 characters | subtitle norms |
| VO pace | ≤ 2.5 wps; 15 s ≈ 35 words, 20 s ≈ 45, 30 s ≈ 70, 60 s ≈ 140 (minus 10–15 % for pauses) | 150 wpm; top brands 2.3–2.9 wps |
| Visual change | every 1.5–3 s | |
| CTA | 1–5 words | top brand range |

## On-screen text (kinetic type)
- Fragments are allowed and good: kinetic type runs on rhythm. Splitting one sentence across two cards (setup / payoff) is a strong device. Parallel lists that repeat one word with new endings work.
- Every card must make sense to a muted viewer in sequence. A spoken line of ≤ 7 words can go on screen whole; don't strand fragments that need the audio.
- Prefer the product's own words as text: real button labels, real prompts, real toasts, real status lines. Zooming into UI text often replaces a caption.
- Full stops: fine on staccato statements ("Sent. Before tomorrow.", "All 1,126 payouts. One CSV."); none on step labels, UI labels or the CTA/URL.
- Steps: as numbered labels synced to an on-screen counter ("1 · Open export"), using the real UI label where one exists. Never unnumbered instructions.
- Numbers as numerals; units explicit; before→after with an arrow ("3 h → 1 click").
- One accent colour reserved for the payoff word/number.

## VO (only when asked)
- Written for the ear: short sentences, contractions, no lists of features.
- Complements the screen; never reads the card verbatim. Every claim that matters is also on screen.
- One audio focus at a time: duck music under VO.

## Banned (rewrite on sight)
**Words:** seamless, powerful, intuitive, robust, cutting-edge, next-level, revolutionary/revolutionize, game-changer/game-changing, supercharge, unlock, effortless, elevate, empower, leverage, transform (as a vague verb), streamline, reimagine(d), magic(al) (unless the brand uses it), "in seconds" (unless measured), "save hours" (unless shown).
**Openers:** "Introducing" / "Meet" / "We're excited to announce" as the first line; defining the category ("X is a platform that…"); a logo sting; founder journey montage; "We added AI".
**Structures:** "Not X. Y." negating a claim nobody made; a rhetorical question immediately answered by itself; "Say goodbye to…"; "X, reimagined"; "The future of X is here"; "Imagine…" as filler; three-adjective stacks; tidy rhyming taglines; "all-in-one platform for modern teams".
**Visual-copy tells:** three feature cards in a row; title over a dimmed screenshot; logo docked in a corner.
**Competitor test:** if the line works under a competitor's logo, it's generic; rewrite with this product's specific noun, number or action.
**Walkthrough captions:** "Click Export, pick the payouts", "Then the dates: last 90 days", "Open anyone to see…" (unnumbered imperatives narrating the UI). Show it, or number it on a counter.
**UI-mechanics stakes:** pages, pagination, tabs, rows per page, toggles, dropdowns as the problem ("That's 57 pages of payouts").
**Invisible-state captions:** a line that depends on something the viewer never saw happen ("Already set: last 90 days").
**Vague lines:** no number, name, real UI label or concrete object ("Close the tab. Keep working").

## Allowed at the end
- One benefit tagline before the CTA, tied to the feature ("Less admin. More referrals."). Log it in the ledger as a tagline, not a measured claim, and never put a number on it.
- The logo's one-line descriptor ("Referral & affiliate programs for Shopify.") is lockup art under the logo, not a separate caption.

## Truth
- Every claim, number, label and customer name maps to a row in the claims ledger with a source.
- Never derive claims the source didn't make (no converting times into multipliers, no rounding up).
- Illustrative data is marked `(illustrative)` in the ledger and never presented as a result.
- No invented testimonials, prices, user counts, or awards. No naming or mocking competitors.

## CTA
- One action: verb + where/what. Patterns: availability ("Live now on all plans"), command ("Try ⌘K → Summarize"), destination ("product.com/feature"), question + URL.
- Show it (and say it if VO) in the last 2–3 s; hold ≥ 2 s. Add an offer if there is one.
