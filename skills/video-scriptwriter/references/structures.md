# Structures (archetypes)

Pick by goal and length, then let the story bend it. Times are targets; durations must sum to the total. Beat names map to motion-director: `hook | problem | turn | proof | payoff | cta`.

## Feature videos (one feature)

### F1 · Micro glimpse (10–15 s): the default for changelog/X posts
| Beat | 12 s example | Job |
|---|---|---|
| hook | 0–2 | Feature already working on something recognisable, or the result first |
| proof | 2–9 | One task end to end in real UI: 2–3 verbs (pick → apply → see) |
| cta | 9–12 | Feature name + availability ("Live for all plans"), logo; hold ≥ 2 s |

### F2 · Before → after (15–20 s): best when the old way is visibly painful
| Beat | 18 s | Job |
|---|---|---|
| hook | 0–2 | Contrast line or relatable moment |
| problem | 2–5 | The old way failing on screen (wait, mess, wrong result) |
| turn | 5–7 | The feature arrives as one obvious action (click/toggle/command) |
| proof | 7–13 | Same task, now fast and clean; often the same shot improved |
| payoff | 13–15 | The result + one real number |
| cta | 15–18 | Name + CTA, logo |

### F3 · Same task, two outcomes (15–30 s): great for AI/quality features
hook (the complaint) → result *without* the feature → add the feature in one action → improved result → 3–5 fast variants (~0.5–1 s each) → CTA (often the in-product command).

### F4 · Action ladder (20–45 s): multi-step or AI-agent features
hook (result first or the moment of need) → first concrete action/prompt in close-up (6–25 real words) → playful status beat → result, camera pulls back → 1–2 follow-ups, each adding one capability → scale shot (gallery, counter) → 3–6-word line → logo.

### F6 · Hook chain (35–45 s): the default for a single-feature video
One person, one deadline, one task done on screen; every line is a hook (see SKILL.md "Hook chain").
| Beat | 40 s (ReferRush Exports) | Job |
|---|---|---|
| hook | 0–1.4 | Time stamp: "11:48 PM." (the product is already on screen with the stake number visible) |
| problem | 1.4–4 | Role + number in the viewer's units: "Your accountant needs 1,126 payouts." |
| turn | 4–6.4 | Promise with a count: "Here's the file. In 3 clicks." |
| proof | 6.4–11.4 | Numbered steps on a counter, ~1.6 s each: "1 · Open export" / "2 · Last 90 days" / "3 · Export" |
| turn | 11.4–16 | The mechanic as Q&A over the real toast: "Over 30 days?" / "We email it when it's ready." |
| proof | 16–22.6 | Result states, one noun or number each: "Ready in your inbox." / "All 1,126 payouts. One CSV." |
| payoff | 22.6–28.4 | Bonus + loop closed: "Total included: ₹2,48,600" / "Sent. Before tomorrow." |
| proof | 28.4–32.4 | Breadth: one line over 4 × 1 s labelled shots: "Export your other lists, too." |
| payoff | 32.4–37.4 | Callback "1,126 payouts → 3 clicks." then benefit line "Less admin. More referrals." |
| cta | 37.4–40 | Logo + descriptor + one action: "Get started at referrush.com" |

### F5 · Changelog roundup (30–60 s): several small features
name/version card (≤ 7 words) → 3–4 chapters of: imperative card (4–7 words, parallel grammar: "Filter by anything", "Share in one click") + 8–12 s demo → lockup. Keep each chapter's card grammar identical.

## Launch / promo films

### P1 · Problem → turn → proof → payoff (30 s): Sanji / motion-director default
| Beat | Share | 30 s |
|---|---|---|
| hook | ~8 % | 0–2.5 |
| problem | ~12–15 % | 2.5–7 |
| turn (product named) | ~8 % at 20–30 % in | 7–9.5 |
| proof (3–6 verbs, one per beat) | ~40 % | 9.5–21.5 |
| payoff (biggest moment, once, 60–80 % in) | ~15–20 % | 21.5–26 |
| cta (claim + end card, hold 2–3 s) | ~13–15 % | 26–30 |

### P2 · Kinetic manifesto (45–75 s)
Stat or "what if" split across cards → product name by ~7 s → rhythmic list of single words → live counter/proof → 2–4 chapters (2–4-word card + demo) → "your turn" line → URL. Needs strong music; good for brand launches.

### P3 · Founder note (40–55 s, VO ~110–130 words)
Name within 4 s → one-line definition over real examples → 2-step how-to → "unlike other X…" (without naming them) → borrowed proof (users, community output) → human close → where to try it.

### P4 · Story spot (45–80 s): live-action or character-led
60–70 % builds one repeated pain image → the product as one 1–3 s action → payoff mirrors the opening shot → ≤ 5-word claim → tagline/URL. Product appears late by design; use only for brand awareness.

## Paid social ads (15–30 s)

### A1 · Villain → hero (Fraser Cottrell pattern)
hook (0–3) → old way as the villain (3–7) → product as the hero, shown (7–14) → visible proof/test (14–20) → handle the #1 objection (20–24) → CTA + offer (24–30). Brand visible by 5 s.

### A2 · ABCD (Google)
**A**ttention: fast, high-contrast open. **B**rand: product/brand in by 5 s. **C**onnect: one focused message shown through the product experience. **D**irect: CTA shown (and spoken if VO). Make 3 hook variants on one body.

## Scaling rules
- 10–15 s → 3 beats; 15–25 s → 4–5; 30 s → 5–6; 45–60 s → 6–8. Each demo beat 3–6 s in short films, 8–15 s in long ones.
- Change something on screen every 1.5–3 s; text-heavy cards get the longer end.
- Last visual change lands by ~85–90 %; the end card holds quiet.
- Always offer a 15 s cutdown for anything ≥ 30 s (hook + strongest proof + CTA).
- Hook chain timing: stake by 1.5 s, promise by 4–6 s, the result on screen by ~16 s (40 % in), callback at ~80 %.
